# Julai Portfolio — Holliness Julai Mwawasi

This repository contains the professional portfolio website for **Holliness Julai Mwawasi**. It showcases Holliness’ background, skills, projects, and contact information. The portfolio is intended to represent professional work, development projects, and academic achievements.

---

## Overview

- A responsive, single-page portfolio built with HTML, CSS and a small Node.js/Express backend for contact form handling.
- Highlights education, technical skills, interests, and project examples including deployed demos and downloadable artifacts (CV, thesis, and other project files).

## Built With

- HTML, CSS, JavaScript
- Node.js, Express
- Nodemailer (contact form email delivery)
- Other libraries: body-parser, cors

## Features

- About, Education & CV download
- Skills, Programming languages and Interests
- Projects list with links to demos and GitHub repositories
- Contact form that uses a simple Express backend to send messages via email
